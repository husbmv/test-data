# 测试工具

一个基于 PyQt6 的桌面工具，用于自动生成通信光缆工程相关的测试资料 Excel 表格。所有输出表格均经过格式化处理，每张表独占一个 A4 打印页。

## 主要功能

### 一、测试资料

#### 1. 单盘测试（附表 2 光缆单盘检验测试记录表）

根据所选光缆型号（GTYA / GTYA53）、芯数（4 / 8 / 12 / 24 / 48 / 96 / 144）和页数，自动生成光缆单盘检验测试记录表。

- 出厂盘号自动按 `C + 日期 + 三位随机数` 规则生成（日期为 6 个月内的随机一天）
- 测试衰耗值在 0.185 ~ 0.200 dB 范围内随机生成，保留 3 位小数
- 测试光纤长度在 2.000 ~ 2.010 km 范围内随机生成
- 48/96/144 芯自动按两栏 / 多表排版：48 芯一张表 24 纤序号 ×2 列；96 芯拆成 2 张表（1-48、49-96）；144 芯拆成 3 张表
- 每张表占 33 行，A4 纵向打印，每张表独占一页

输出文件：`{型号}-{芯数}B1单盘测试.xlsx`

#### 2. 表三（用户段接头衰耗测试表）

读取所选 Excel 文件的"数据"工作表（地址、芯数、光缆总长、接头数四列），为每条记录的每个接头自动生成一张表三。

- 损耗值在 0.002 ~ 0.021 dB 范围内随机生成
- 48/96/144 芯按双栏 / 多表排版：96 芯拆 2 张表，144 芯拆 3 张表
- 每张表占 30 行，A4 横向打印，每张表独占一页

输出文件：`表三接头损耗表.xlsx`

#### 3. 表四（用户段光纤线路衰减测试记录）

读取所选 Excel 文件的"数据"工作表，为每条记录生成一张表四。光缆总长自动从米换算为公里（保留 4 位小数）。

- 损耗值在 0.131 ~ 0.141 dB 范围内随机生成
- 平均损耗值在 0.191 ~ 0.202 dB/km 范围内随机生成
- 48/96/144 芯按三栏 / 多表排版：每张表展示 48 芯，96 芯拆 2 张表，144 芯拆 3 张表
- 每张表占 21 行，A4 横向打印，每张表独占一页

输出文件：`表四损耗表.xlsx`

#### 4. 合并文件

把多个已生成的 Excel 文件合并到一个工作簿中，每个源文件对应一个工作表（ sheet 名取文件名）。

- 完整复制源表的单元格值、字体、边框、对齐、填充、数字格式
- 复制列宽、行高、合并单元格
- 复制分页符、页面设置（纸张、方向、缩放）、页边距、打印区域
- 带进度条和日志输出，单文件失败不影响其他文件

输出文件：`测试资料.xlsx`

#### 5. 添加 / 清空文件

- 单文件选择：把所选 Excel 的内容加载到表格里预览（用于表三、表四）
- 多文件选择：把多个 Excel 加入待合并列表（用于合并文件）
- 一键清空当前预览表格、日志和文件路径

### 二、竣工资料

#### 1. 加载数据库

读取所选 Excel 文件的"数据库"工作表，把项目列表加载到表格里。

#### 2. 查找表格

按订单号在所有单元格中模糊搜索（不区分大小写），高亮并定位到匹配项；状态栏显示"结果 x / 共 y 个"。

#### 3. 行选中自动填写

点击表格中任意一行，自动解析并把以下字段填到对应输入框：

- 订单号、项目编号、合同号、订单名称、结算单号、施工单位、抽审情况、审定金额
- 成本（取第 15 列）
- 含税金额 = 成本 × 1.09（保留 2 位小数，银行家舍入）
- 终验款 = 含税金额 × 0.90
- 尾款 = 含税金额 − 终验款

#### 4. 制作段落清单

根据所选 Excel 的"数据"工作表，按每 24 行一页自动拆分，生成段落清单。每页包含订单编号、合同编号、项目名称、项目编号、工程名称、施工单位、序号 / 段落 / 型号 / 数量等列。

- 单项名称自动从订单名称中剥离项目名称前缀
- 光缆长度自动从米换算为公里（保留 3 位小数）

输出文件：`段落清单.xlsx`

#### 5. 清空内容

一键清空竣工资料所有输入框（订单号、合同号、各项金额等）。

## 安装与运行

### 开发环境运行

```bash
pip install PyQt6 openpyxl pandas python-dateutil
python 测试资料-UI.py
```

### 打包为 exe

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

或直接双击 `build.bat`。打包脚本会自动检查环境、清理旧的 `build/` 和 `dist/`、用 `测试工具.spec` 调用 PyInstaller。最终产物在 `dist/测试工具/测试工具.exe`，整个文件夹可直接拷贝分发。

## 输入文件格式

### 表三 / 表四所需的"数据"工作表

| 列 | 字段 | 说明 |
|----|------|------|
| 1  | （忽略） | |
| 2  | 地址 | 用户段地址，会显示在表头 |
| 3  | 芯数 | 形如 `48D`、`96B1` 等，末位字符会被去掉 |
| 4  | 光缆总长 | 表三：任意数值；表四：单位米，自动除以 1000 |
| 5  | 接头数 | 整数；表三会按此数量为该地址生成对应数量的表 |

### 竣工资料所需的"数据库"工作表

| 列 | 字段 |
|----|------|
| 2  | 订单号 |
| 3  | 订单名称 |
| 4  | 结算单号 |
| 5  | 项目编号 |
| 6  | 项目名称 |
| 7  | 合同号 |
| 8  | 施工单位 |
| 13 | 抽审情况 |
| 14 | 审定金额 |
| 15 | 成本 |

## 打印 / 分页说明

所有生成的 Excel 都已设置好：

- 显式分页符：每张表后插入，强制每张表从新的一页开始
- A4 纸张：单盘测试纵向，表三 / 表四横向
- 100% 缩放，不压缩：保证字体和边框按真实大小打印
- 打印区域：覆盖到工作表最大行

合并文件时上述设置会被一并复制到合并后的工作簿，所以合并后的 Excel 同样每张表独占一页。

```
test-data-main/

├── 单盘测试.py           # 单盘测试表生成
├── 表三.py               # 表三接头衰耗表生成
├── 表四.py               # 表四衰减测试记录生成
├── 段落清单.py           # 段落清单生成
├── excel合并.py          # 多 Excel 文件合并
├── 测试工具.spec         # PyInstaller 打包配置
├── build.ps1             # PowerShell 打包脚本（推荐）
└── build.bat             # cmd 打包脚本（备选）
```
